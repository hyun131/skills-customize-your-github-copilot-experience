
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a classic Hangman game in Python that uses strings, loops, and conditionals to create an interactive word-guessing experience.

## 📝 Tasks

### 🛠️ Build the Core Game Logic

#### Description
Create a Python program that selects a random word, asks the player to guess letters, and updates the hidden word as correct guesses are made.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list
- Display the hidden word as underscores or blanks for unrevealed letters
- Accept letter guesses from the player
- Track the number of incorrect guesses remaining
- Reveal correctly guessed letters in the correct positions
- End the game when the word is fully guessed or attempts run out
- Print a clear win or lose message at the end

### 🛠️ Improve the Game Experience

#### Description
Polish the game so it feels more complete and is easier to replay across multiple rounds.

#### Requirements
Completed program should:

- Show the player's guessed letters and remaining attempts
- Allow the player to play again after a round ends
- Provide clear feedback for correct and incorrect guesses
- Keep the code organized with functions for word selection, guessing, and game flow
- Use readable variable names or simple comments to make the code easier to understand
